# SECURITY.md

## Security Policy

We take the security of **e-Studies App** seriously.

If you discover a security vulnerability, please report it responsibly.

---

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅         |
| Older   | ❌         |

---

## Reporting a Vulnerability

Please **do not** open a public issue.

Instead, report security issues by:

* Opening a private GitHub Security Advisory, or
* Contacting the project maintainer directly

Include as much detail as possible:

* Description of the vulnerability
* Steps to reproduce
* Potential impact

---

## Disclosure Process

* Vulnerabilities will be reviewed promptly
* Fixes will be released as soon as reasonably possible
* Credit will be given where appropriate
