# Architecture Decision Records (ADR)

This directory contains Architecture Decision Records for **e-studies-app**.

We use ADRs to document:
- Important architectural choices
- The context behind decisions
- Considered alternatives
- Consequences

---

## Format

We follow a lightweight ADR format inspired by Michael Nygard.

Each ADR is:
- Immutable once accepted
- Sequentially numbered
- Written in Markdown
