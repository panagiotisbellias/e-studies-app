# Support

Thank you for using e-Studies App!

## Getting Help

Before asking for help, please check:

* [README.md](README.md) for installation, usage, and development information.
* [CONTRIBUTING.md](CONTRIBUTING.md) for contribution guidelines.
* Existing [GitHub Issues](https://github.com/panagiotisbellias/e-studies-app/issues) for known problems and previous discussions.

## Questions and General Help

For questions about using or developing e-Studies App, please open a GitHub Issue with enough information to understand the question or problem.

Please include, where relevant:

* What you are trying to do
* What you expected to happen
* What actually happened
* Java version
* Operating system
* Relevant error messages or logs

## Bug Reports

For reproducible bugs, please use the [bug report template](https://github.com/panagiotisbellias/e-studies-app/issues/new?template=bug_report.md).

## Feature Requests

For new functionality or improvements, please use the [feature request template](https://github.com/panagiotisbellias/e-studies-app/issues/new?template=feature_request.md).

## Security Issues

Please do **not** report security vulnerabilities through public GitHub Issues.

See [SECURITY.md](SECURITY.md) for information about reporting security vulnerabilities privately.
