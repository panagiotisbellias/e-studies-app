# Project Roadmap

This document outlines the planned direction of the **e-studies-app** project.
Dates and priorities may change based on feedback and capacity.

---

## 🎯 Goals

- Provide a stable, maintainable platform for e-studies management
- Improve developer experience and testability
- Maintain high code quality and security standards

---

## 🚀 Near-term (Next 1–2 releases)

- Improve test coverage (unit & integration)
- Stabilize CI pipelines (CodeQL, Dependabot)
- Documentation improvements (architecture, ADRs, contributing)
- Refactor legacy or deprecated APIs where applicable

---

## 🛠 Mid-term

- Performance optimizations
- Enhanced accessibility (a11y) compliance
- Better error handling and observability
- Modularization of core features

---

## 🌱 Long-term / Ideas

- Plugin or extension system
- Multi-tenant support
- API versioning strategy
- Improved analytics and reporting

---

## 🤝 Contributions

Roadmap items are open for discussion.
Feel free to propose changes or new ideas via GitHub Issues.
